MEGA MASTER PROMPT — PERSONAL SAVING GOAL TRACKER WEBSITE

Build a modern, clean, minimal, mobile-first personal savings tracker web application focused primarily on saving money toward goals, not expense tracking.

The core idea is:

«“I manually add the money I save every day, choose where that money came from, and the website automatically tracks my total savings and progress toward my main goal.”»

The application must use real persistent user data, not demo-only data.

---

1. PRODUCT VISION

Create a personal finance web app that feels:

- Extremely clean
- Minimal
- Fast
- Simple to understand
- Mobile-first
- Interactive
- Modern
- Premium but not complicated

The user should be able to open the website and understand their financial progress within 2–3 seconds.

Do NOT make it look like complicated accounting software.

The primary question the dashboard should answer is:

«“How much have I saved, how much is left for my goal, and where did my savings come from?”»

Features:

6. SAVING LOGIC

Every saving transaction must contain:

- Unique transaction ID
- User ID
- Amount
- Category ID
- Date
- Optional note
- Created timestamp
- Whether it is linked to the main goal

Example:

Amount: ₹500
Category: Part-time
Date: 4 Sep 2026
Linked to Main Goal: Yes

When saved:

1. Store the transaction in the database.
2. Update category totals.
3. Update main goal linked amount.
4. Update progress percentage.
5. Update remaining amount.
6. Update today's total.
7. Update monthly total.
8. Update saving streak if applicable.
9. Update goal completion estimate.

All calculations must be based on real database transactions.

Never hardcode financial values.

14. MAIN GOAL CALCULATIONS

Calculate:

Total Goal Savings
= SUM(all transactions linked to the goal)

Progress:

Progress %
= (Saved / Target Amount) × 100

Remaining:

Remaining
= Target Amount - Saved

Never allow negative remaining values to display incorrectly.

If saved amount exceeds target:

Show:

🎉 Goal Completed

and optionally:

₹5,000 over target

48. REAL-DATA REQUIREMENT

This is extremely important:

The application must NOT present fake financial numbers after deployment.

Use demo/seed data only during development if necessary.

FINAL DESIGN DIRECTION

Build the product as a beautiful personal savings companion, not a traditional finance/accounting application.

The most important interaction is:

SAVE MONEY → SELECT SOURCE → LINK TO GOAL → WATCH PROGRESS

The interface should be so simple that a user can add today's saving in seconds.

Use real persistent financial data, Indian Rupee formatting, custom categories, goal linking, automatic calculations, and a clean interactive mobile-first UI.

The final product should feel polished enough to be used as a real personal savings application.
